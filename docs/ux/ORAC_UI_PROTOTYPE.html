What changed vs. the screenshots

Design mock only. Presentation changes, no business logic, permissions or workflow touched. Numbers refer to PRIORITIZED_IMPROVEMENTS.md.

  1. #1 One content widthEvery page uses the same 1440 px wrapper and 28 px gutter (16 px on mobile). The page edge no longer shifts between routes.
  2. #2 Tiles that mean somethingNeutral by default. Tinted with a left rule only when a role has something waiting. Zero-count priorities collapse to one "Nothing waiting" line. "View details →" removed from tiles (the tile is the link).
  3. #3 One selected-state languageNav = navy fill (also lights up the dropdown group of the current page). Page tabs = underline. Filters = soft tint chip. Primary button = always navy.
  4. #4 MobileCompact 2-up tiles, one-row scrolling nav with edge fade, tables become stacked rows, Sign out inside the avatar menu, no horizontal page scroll, Inventory form moved behind a button. Use the Mobile preview.
  5. #5 Heading scalePage title, section title, eyebrow and label, all sentence case.
  6. #6 ORAC GuidePinned bottom-right with reserved space under the content. Icon-only on mobile.
  7. #7 One status pillSame size, dot + text, one colour map. No raw underscores. "Active" is now info, not grey.
  8. #8 Table conventionsNumbers right-aligned with tabular figures, status next to the identifier, empty Technician/Site columns removed, lone tables paired with the pipeline panel instead of an empty half.
  9. #9 Type floor12 px minimum, 13–14 px body, 13 px labels, darker secondary text and links (no pale amber or grey links).
  10. #10 Dashboard compositionPipeline card became a slim strip (or a side panel), tiles in a 12-column grid, row that matches the active priority is highlighted (Supervisor).
  11. #11 IconsLine icons only (no emoji), SVG chevrons instead of the letter "v".
  12. #12–16 Forms, Inventory, Admin44 px controls, one label style, helper text under fields, checkbox statement in body text. Inventory explains only the row that needs reordering and the movement form is collapsible. Admin "Disable" is clearly destructive and spaced from "Edit".
  13. #17 Header (reworked after your feedback)One 72 px bar in three zones: brand | navigation | account. Nav is 16 px with an icon per item, 46 px tall, beside the logo instead of a cramped second row. The account chip shows name and role. No permanent "Online" pill: when offline a full-width notice appears under the bar and the avatar dot turns amber (try "Simulate offline"). Dark mode moved into the account menu.
  14. Mobile bottom tab barUnder 768 px the top nav becomes a bottom tab bar (icon + label, 58 px targets) so the thumb reaches everything. Groups open as a sheet above it.
  15. Roomier and larger overallBase text 16 px (was 14), 44 px controls, larger tile numbers, more padding in cards and tables, icon chips on tiles, clickable table rows.
  16. v3: spec applied (DESIGN_SYSTEM_SPEC.md)Base text is now 16 px to match your real index.css (v2 used 15 px). Corners are 8 px on controls and tables, 12 px on cards. Input borders use your real #64748b token (4.76:1). One type scale, 4 px spacing scale and shared tokens (see Screen: Design system reference).
  17. v3: three layoutsMobile under 768 px, Tablet 768–1023 px, Desktop 1024 px and up. The header nav is always labelled and spread evenly; below 900 px it becomes a labelled bottom tab bar. Use the Preview buttons.
  18. v3: densityComfortable (default) and Compact (12×16 cell padding, 40 px controls) for heavy table users.
  19. v3: statesLoading skeletons (tick "Simulate loading"), empty, error, success toast, offline and session-expired patterns, plus forced hover / focus / active / disabled / loading examples on the Design system screen.
  20. v3: documentsScreen "Quotation & invoice documents" shows an A4 layout reference with header band, parties, line items, totals, terms, signature and footer. Use Print to see the print stylesheet.
  21. v3.1: card hierarchyOn tiles and summary strips the label (the purpose, e.g. Total quotes) is now 18 px bold in primary text, and the count is smaller (28 px, weight 600, secondary text). Counts still turn amber or red when something needs action.
  22. v3.2: visible buttons, larger textButtons are 16 px bold with a 2 px outline (secondary) or a filled navy with a shadow (primary). Field labels, table sub-lines, tile descriptions and section labels went from 14 px to 16 px. See Design system reference, Page anatomy.
